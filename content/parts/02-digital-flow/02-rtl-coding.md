## 一句话定义

RTL（寄存器传输级）用硬件描述语言写出「时钟沿上寄存器如何更新、组合逻辑如何计算」，是数字电路的可综合实现稿。

## 作用与功能

RTL 不是给 CPU 执行的软件程序，而是在描述硬件结构：哪些量要存起来（寄存器），哪些量即时算出（组合网络），模块之间如何连线。Verilog 和 SystemVerilog 是业界最常见的描述语言，后者在验证和接口上更强；VHDL 在部分航空、工业和欧洲团队仍常用。同一功能可以用多种写法，综合器认的是「可综合子集」：能映射成触发器、组合门、存储器的那一部分。延迟等待、文件读写、动态内存这类仿真专用写法，不能直接变成硅上的门。

模块划分决定可维护性。按功能切（定时器、UART、仲裁器），按时钟域切，按可复用 IP 边界切，都比把整颗芯片写成一个文件更安全。命名、复位策略、握手协议要在编码规范里统一，否则验证和后端会不断回头问「这个信号到底同步吗」。入门时先练「一个时钟、一个复位、清晰输入输出」的小模块，再拼系统。读别人的 RTL，优先找时钟、复位、握手和存储器边界，这四处最容易藏跨时钟和不可综合写法。把模块顶层端口写得像规格里的接口清单，验证和软件才不用猜。

## 在全流程中的位置

RTL 夹在架构和验证/综合之间。它是前端的主要交付物，也是功能验证的被测设计（DUT）。综合读取 RTL 和约束，生成门级网表；DFT 插入扫描时也要理解寄存器在哪里。FPGA 和 ASIC 可以共用大部分 RTL，差异通常在时钟原语、存储器和 IO。

## 典型应用场景

写一个可综合的计数器和 FIFO，是训练班的经典作业。项目里则是实现 DMA 描述符状态机、总线桥、中断控制器。团队还会把第三方 IP 的 RTL 或加密网表包进顶层。编码评审关注可综合性、复位、跨时钟和接口一致性，而不是文风是否华丽。一份能过评审的 RTL，通常让不写这个模块的人也能在半小时内指出时钟沿和握手发生在哪。

## 一个小例子

「每个时钟把计数加一，到上限回零」听起来像程序循环，RTL 里却是：用寄存器记住当前值，组合逻辑算下一个值，时钟沿到来时更新。没有时钟，硬件不会「自动往下跑一行」。

```text
每个时钟沿:
  若复位: count <= 0
  否则若使能: count <= count + 1
组合逻辑只负责算出 next_count, 不「等待」
```

## 本节知识点

- RTL 描述寄存器如何更新、组合逻辑如何计算。
- Verilog/SystemVerilog/VHDL 是语言，可综合子集才对应电路。
- 仿真能跑的写法，不一定能变成门级硬件。
- 按功能、时钟域和 IP 边界划分模块。
- RTL 是验证的 DUT，也是综合的输入。
- FPGA 与 ASIC 可共享核心 RTL，原语和存储器需适配。
- 规范的复位、命名和握手，能减少后续返工。
