## 一句话定义

IP 是可复用的设计积木；SoC 集成是把处理器、存储、外设和加速器按总线和地址地图拼成一颗能跑软件的系统芯片。

## 作用与功能

现代芯片很少从每一根门线开始自研。软 IP 以 RTL 或网表形式交付，你可以针对目标工艺再综合，便于改参数和修接口。硬 IP 以已经完成版图的宏交付，如高速 PHY、嵌入式存储器、模拟模块，性能和工艺绑定，集成时主要是摆位置、接电源和包一层数字外壳。固件、驱动和验证环境有时也随 IP 一起走，否则你只买到了「会动的核」，买不到「能用的核」。

SoC 集成的日常动作是挂总线和画地址。CPU、DMA、外设通过片上总线或互连矩阵互相看见；每个从设备占据一段地址，软件用读写作配置和数据搬运。中断号、时钟、复位、DMA 握手、调试口，都要在集成时接通，而不是等软件上机才发现缺线。集成还要统一命名、统一复位释放顺序、统一存储器映射文档，让硬件同事和软件同事看同一张图。

复用的价值是进度和风险：成熟 USB、以太网、DDR 控制器不必重写。代价是接口版本、时钟假设、可综合性与你的流程是否合拍。集成不是连线游戏，而是一次小型系统设计。

## 在全流程中的位置

架构阶段选型 IP、划分总线层次和地址空间，输出内存映射和中断表。RTL 集成把各 IP 实例化并补上胶合逻辑：时钟门控、复位同步、FIFO、协议桥。验证从单 IP 自测走到系统级：启动、外设枚举、DMA 搬运、低功耗切换。综合和后端把硬 IP 当宏处理，软 IP 跟着芯片一起走流程。签核要确认硬 IP 的工艺版本、金属层和天线规则与当前节点一致。软件则在仿真或 FPGA 原型上提前适应这张地址地图。

## 典型应用场景

手机应用处理器、汽车 MCU、无线 SoC、人工智能加速卡，都是「少量自研加大量 IP」。初创团队做第一颗芯片，往往自研算法加速器，购买 CPU、接口和存储器编译器。FPGA 上做 SoC 原型时，也是同一套集成思维：软核或硬核处理器、BRAM、外设 IP 挂到总线上，先让软件跑起来。

## 一个小例子

集成立一颗迷你 SoC：一颗 CPU 软核、一块片上 SRAM、UART、定时器、自研加速器。先定总线：CPU 指令和数据走高速口，UART 和定时器走低速外设桥，加速器带 DMA 口。再定地址：SRAM 从零开始，外设各分 4KB 窗口，加速器寄存器另开一段。清单至少包括：每个从设备的时钟和复位、中断连到哪里、DMA 请求是否接好、启动 ROM 是否指向正确入口、地址文档是否与 RTL 一致。缺一项，软件就会在「写了寄存器没反应」上耗掉一周。

## 本节知识点

- 软 IP 以 RTL 或网表交付，可再综合
- 硬 IP 是绑定工艺的版图宏，集成时当黑盒摆放
- SoC 集成的核心是总线挂接和地址映射
- 中断、时钟、复位、DMA 都要在集成时接通
- 内存映射文档是软硬件的共同契约
- 验证要从单 IP 走到启动和系统级场景
- 集成检查清单能避免「连上了但软件看不见」
