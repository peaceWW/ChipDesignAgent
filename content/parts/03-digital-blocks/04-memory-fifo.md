## 一句话定义

存储器用来保存可按地址读写的数据；FIFO 是按先进先出秩序传递数据的弹性缓冲，专门吸收两端节奏不一致。

## 作用与功能

数字芯片里的「记得住」并不只有触发器。少量配置和流水中间值用寄存器或寄存器堆最合适，按地址读出、按写端口更新，访问最快，但每位面积贵。更大的表、帧缓存、指令缓存通常用 SRAM：同一时刻按地址读写一块阵列，容量大、速度仍能跟主时钟走。开机常量、微码、查找表则放进 ROM 或一次可编程存储，正常工作时只读。片外还有 DRAM、Flash，那是另一套接口故事，本章先抓住片上这几类。

FIFO 不是另一种神奇存储介质，而是一种用法：写入端不断推进写指针，读出端推进读指针，中间是一块 SRAM 或寄存器阵列。同步 FIFO 的读写共用一个时钟，用来解耦同域里两个模块的突发差异。跨时钟 FIFO（异步 FIFO）两边各用自己的时钟，指针用格雷码或专用同步方式跨越，专门承担 CDC 数据通路。满、空、将满、将空这些标志，就是给两端做反压和唤醒的语言。

选错存储形态，后面全是代价：该用 FIFO 却用共享寄存器，两端会互相踩脚；该用 SRAM 却全用触发器，面积和漏电一起爆。

## 在全流程中的位置

架构阶段按容量、端口数、延迟和时钟域选定存储器种类，并决定哪些边界放 FIFO。RTL 里寄存器堆可直接写，SRAM 和 ROM 多用工艺库或生成器实例化，仿真要用对应模型。综合通常不把大块存储拆成门，而是保留存储器宏。物理设计要给宏留位置、绕电源和走线通道。验证必须覆盖满写、空读、同时读写和跨时钟指针同步。低功耗设计还会给存储器单独的休眠和外设掉电策略。

## 典型应用场景

CPU 的寄存器堆、缓存和 TLB，GPU 的片上缓冲，DMA 通道两侧的 FIFO，显示控制器的行缓存，通信 IP 的弹性缓冲，都是日常用例。跨时钟场景几乎必见异步 FIFO：高速接口收包时钟与系统时钟不同，音频采样钟与处理器钟不同。FPGA 里 BRAM 常被推断或实例化成这些角色，概念与 ASIC 一致，只是容量台阶按块来。

## 一个小例子

UART 接收字节的速度由串口波特率决定，处理器读取却是一阵一阵的。若每到一字节就打断 CPU，系统会忙死；若只设一个寄存器，CPU 稍晚就会丢字节。于是在接收器和总线之间放一个同步 FIFO：前端按串口节拍写入，CPU 一次抽走多字节。若这颗 UART 的比特采样钟和总线钟本就不是同一个，就把 FIFO 换成异步的，让存储阵列同时完成缓冲和跨时钟。满标志还可用来通知对端暂停，避免覆盖未读数据。

## 本节知识点

- 寄存器堆适合小容量、低延迟的按地址访问
- SRAM 承担片上较大的可读写阵列
- ROM 存放只读常量和查找表
- 同步 FIFO 解耦同一时钟域的两端节奏
- 异步 FIFO 同时完成缓冲和跨时钟传递
- 满空标志是反压语言，空读满写都是功能缺陷
- 大块存储在综合时通常保留为宏，不拆成门
